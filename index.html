Навыки

Что я использую в работе

5

HTML5

Каркас вашего сайта или приложения. Современная семантическая разметка помогает поисковикам лучше понимать страницы.

3

CSS3

Язык стилей, который отвечает за внешний вид: цвета, сетки, анимации и адаптив под любой экран.

JS

JavaScript

Оживляет страницы: слайдеры, окна, вкладки, подсказки и обмен данными с сервером.

jQuery

jQuery

Библиотека для быстрой работы со страницей. В новые проекты подключаю её редко, но с ней работать умею.

React

Библиотека для создания интерактивных web-приложений с удобными и быстрыми интерфейсами.

node

Node.js

Платформа для серверной части: «мозги» продукта, которые обрабатывают запросы и работают с данными.

mongoDB

MongoDB

Нереляционная база данных. Хранит данные вашего сайта или приложения.
